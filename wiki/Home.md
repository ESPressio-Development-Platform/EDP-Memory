# EDP-Memory Developer Wiki

EDP-Memory defines deterministic memory-resource contracts, compile-time memory topology and bounded object-pool/shared-reserve runtime management.

This Wiki is maintained beside the code on `main`. Source code and repository `docs/` remain normative; the Wiki is the internal developer explanation/navigation layer.

## Public entry point

```cpp
#include <ESPressio_Memory.hpp>
```

## Dependencies

Mandatory: EDP-System and EDP-Platform.
